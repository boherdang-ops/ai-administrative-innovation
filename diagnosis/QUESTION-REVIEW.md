# 전체 문항 의도·판단 기준 검토표

draft-2026-10-19.3 / 2026-10-19

공개 예비진단 문항의 목적과 판단 범위를 명시합니다. 복합 요건은 확인 항목을 모두 검토하고 일부 충족을 별도로 선택합니다. 기관은 선택한 응답 범위의 확인 사실만 답합니다. 전문가 진단은 이 흐름에 포함하지 않습니다.

## P01 · AI의 한계 설명

**질문:** 생성형 AI의 답변이 그럴듯해도 사실과 다를 수 있는 이유를 설명할 수 있나요?

**확인 의도:** AI가 틀릴 수 있음을 아는 것과 그 이유를 설명하는 능력을 확인합니다.

**판단할 항목:**

- 사실과 다른 답·없는 출처가 생길 수 있음을 설명
- 결과 확인이 필요한 이유를 설명

**응답 선택지:**

- `consistent` 오류가 생기는 이유와 확인이 필요한 이유를 내 말로 설명할 수 있다
- `supported` 예시나 설명 자료를 보면서 이유를 설명할 수 있다
- `notyet` 틀릴 수 있다는 것은 알지만 그 이유를 설명하기 어렵다
- `unknown` 현재 어느 수준인지 판단하기 어렵다
- `na` 이 능력이 필요한 업무를 맡아보지 않아 판단하기 어렵다

**보완 행동:** AI가 틀린 가상 답변 한 건을 찾아 왜 확인이 필요한지 설명해 보세요.

**완료 확인:** 오류 가능성과 원문 확인의 필요성을 자신의 말로 설명함

## P02 · 출처 대조 경험

**질문:** AI가 제시한 출처·인용을 원문과 직접 대조해 본 경험이 있나요?

**확인 의도:** 출처를 확인해야 한다는 지식보다 실제로 원문을 열어 대조한 경험을 확인합니다.

**판단할 항목:**

- 인용한 원문을 직접 열어봄
- AI 답변의 내용·시행일을 원문과 비교

**응답 선택지:**

- `consistent` 여러 업무에서 출처·인용을 원문과 직접 대조해 보았다
- `supported` 한 번 대조해 보았거나 동료의 도움을 받아 대조해 보았다
- `notyet` AI 답변을 써본 적은 있지만 출처·인용을 원문과 대조해 본 적은 없다
- `unknown` 관련 경험이 있었는지 명확히 기억나지 않는다
- `na` 이 활동을 수행할 업무 기회가 없었다

**보완 행동:** 가상 보고서의 인용 두 곳을 원문과 대조하고 일치·불일치를 적어보세요.

**완료 확인:** 원문 위치·확인일·수정 내용을 남김

## P03 · 근거 없는 조항에 대한 대응

**질문:** AI가 출처가 불분명한 조례 조항을 제시했습니다. 먼저 할 일은 무엇인가요?

**확인 의도:** 그럴듯한 법령 표현을 검증 없이 사용하는지 확인하는 상황판단 문항입니다.

**판단할 항목:**

- AI가 제시한 조항을 아직 확인하지 않은 상황

**응답 선택지:**

- `correct` 현행 원문·시행일을 확인하고 근거가 없으면 사용을 보류함
- `incorrect` 자연스러운 문장이므로 보고서에 바로 사용함
- `unknown` 판단하기 어려움

**보완 행동:** 가상 조항을 현행 원문에서 찾아보고 확인되지 않으면 사용을 보류해 보세요.

**완료 확인:** 원문·시행일 확인 또는 사용 보류 사유를 적음

## P04 · 업무 요청의 구체성

**질문:** AI에 업무를 요청할 때 목적·입력 자료·제약·완료 기준을 구체적으로 적을 수 있나요?

**확인 의도:** 긴 요청문을 쓰는 능력이 아니라 AI가 해야 할 일과 완료 기준을 정하는 능력을 봅니다.

**판단할 항목:**

- 목적: 무엇을 위해
- 입력: 어떤 자료로
- 제약: 지켜야 할 조건
- 완료 기준: 어떤 결과가 필요한지

**응답 선택지:**

- `consistent` 네 가지를 스스로 구체적으로 적어 요청할 수 있다
- `supported` 양식이나 동료의 도움을 받으면 네 가지를 적을 수 있다
- `notyet` 무엇을 적어야 할지 몰라 간단한 지시만 하는 편이다
- `unknown` 현재 어느 수준인지 판단하기 어렵다
- `na` 이 능력이 필요한 업무를 맡아보지 않아 판단하기 어렵다

**보완 행동:** 익숙한 업무 한 건의 요청문에 목적·입력·제약·완료 기준을 각각 한 줄로 적어보세요.

**완료 확인:** 네 요소가 있고 결과를 점검할 기준이 드러남

## P05 · AI와 사람의 역할 구분 경험

**질문:** 한 업무를 AI가 보조할 작업과 사람이 직접 판단할 작업으로 나누어 본 경험이 있나요?

**확인 의도:** 업무 전체를 AI에 맡기지 않고 작업별로 사람의 판단을 남겨본 경험을 확인합니다.

**판단할 항목:**

- AI가 초안·분류·정리를 보조할 작업
- 담당자가 확인·승인할 작업

**응답 선택지:**

- `consistent` 여러 업무에서 AI 보조 작업과 사람의 판단 작업을 나누어 보았다
- `supported` 한 업무에서 나누어 보았거나 도움을 받아 구분해 보았다
- `notyet` AI를 써봤지만 작업별로 역할을 나누어 본 적은 없다
- `unknown` 관련 경험이 있었는지 명확히 기억나지 않는다
- `na` 이 활동을 수행할 업무 기회가 없었다

**보완 행동:** 업무 한 건을 5개 안팎의 작업으로 나누고 AI 보조·사람 확인을 표시하세요.

**완료 확인:** 사람이 판단·승인할 지점이 빠지지 않음

## P06 · 업무 개선의 출발점

**질문:** 일주일 걸리던 업무를 줄이고 싶습니다. 가장 먼저 할 일은 무엇인가요?

**확인 의도:** 도구를 먼저 고르기보다 현재 업무의 병목부터 확인하는지 봅니다.

**판단할 항목:**

- 처리시간과 대기시간은 다름
- 전체 업무 중 바꿀 작업을 먼저 찾음

**응답 선택지:**

- `incorrect` 가장 비싼 AI 도구를 구입함
- `correct` 현재 절차·대기·검토 시간을 나누고 바꿀 작업을 정함
- `unknown` 판단하기 어려움

**보완 행동:** 현행 절차의 작업·대기·검토 시간을 나누어 가장 큰 병목을 찾아보세요.

**완료 확인:** 개선할 작업과 선정 이유가 구체적임

## P07 · 자료 선택과 최소화

**질문:** AI에 제공할 자료를 고를 때 사용 허용 여부를 확인하고 필요한 부분만 정리할 수 있나요?

**확인 의도:** 자료를 많이 넣는 것이 아니라 허용된 자료 중 필요한 부분만 선택할 수 있는지 확인합니다.

**판단할 항목:**

- 기관의 사용 허용 범위
- 개인정보·비공개 정보 포함 여부
- 요청 목적에 꼭 필요한 부분

**응답 선택지:**

- `consistent` 사용 허용 여부를 확인하고 필요한 부분만 스스로 골라 정리할 수 있다
- `supported` 자료 선택·정리에 예시나 담당자의 도움이 필요하다
- `notyet` 어떤 자료를 넣어도 되는지 판단하거나 필요한 부분을 고르기 어렵다
- `unknown` 현재 어느 수준인지 판단하기 어렵다
- `na` 이 능력이 필요한 업무를 맡아보지 않아 판단하기 어렵다

**보완 행동:** 가상 자료 목록을 사용 가능·확인 필요·입력 금지로 구분해 보세요.

**완료 확인:** 자료별 선택 이유와 최소 입력 범위를 설명함

## P08 · 오류 수정 경험

**질문:** AI 결과가 기대와 다를 때 입력 자료·기준·지시문 중 원인을 찾아 고치고 다시 실행해 본 경험이 있나요?

**확인 의도:** 다시 물어본 횟수보다 무엇이 잘못됐는지 찾아 조건을 바꿔본 경험을 봅니다.

**판단할 항목:**

- 입력 자료의 문제
- 판단 기준의 문제
- 지시문의 문제

**응답 선택지:**

- `consistent` 여러 사례에서 원인을 구분해 고치고 다시 실행해 보았다
- `supported` 한 번 해보았거나 도움을 받아 원인을 찾아 다시 실행해 보았다
- `notyet` 결과가 마음에 들지 않아도 원인을 구분해 수정·재실행한 적은 없다
- `unknown` 관련 경험이 있었는지 명확히 기억나지 않는다
- `na` 이 활동을 수행할 업무 기회가 없었다

**보완 행동:** 잘못된 결과 한 건에서 원인 후보 하나를 골라 한 부분만 바꾼 뒤 재실행하세요.

**완료 확인:** 바꾼 부분과 전후 결과·남은 문제를 기록함

## P09 · 민원 자료 보호 판단

**질문:** 주민 이름·연락처가 담긴 내부 민원 자료로 외부 AI를 쓰려 합니다. 어떻게 하나요?

**확인 의도:** 이름만 지우면 충분하다고 판단하지 않고 외부 AI 입력 전 허용 범위를 확인하는지 봅니다.

**판단할 항목:**

- 내부 민원 원문은 아직 외부 AI에 입력하지 않은 상황
- 다른 항목으로도 개인을 알아볼 수 있음

**응답 선택지:**

- `correct` 원문 입력을 멈추고 승인 범위·자료 처리 기준을 확인하며 가상 자료로 연습함
- `incorrect` 이름만 지우면 충분하므로 바로 업로드함
- `unknown` 판단하기 어려움

**보완 행동:** 실제 주민 자료 대신 가상 사례로 입력 가능 범위를 점검해 보세요.

**완료 확인:** 비공개 원문을 입력하지 않고 확인할 담당·절차를 정함

## P10 · 결과 확인 능력

**질문:** AI 결과의 수치·사실·출처를 원자료와 대조해 수정하고 사용 여부를 판단할 수 있나요?

**확인 의도:** AI의 자체 검토와 별개로 담당자가 사실·수치·출처를 직접 확인할 수 있는지 봅니다.

**판단할 항목:**

- 원문 대조
- 수치 검산
- 수정 후 사용 여부 결정

**응답 선택지:**

- `consistent` 원자료 대조·검산 후 수정하고 최종 사용 여부를 스스로 판단할 수 있다
- `supported` 동료나 점검표의 도움을 받으면 대조·수정할 수 있다
- `notyet` AI 결과의 무엇을 어떻게 검증해야 할지 어렵다
- `unknown` 현재 어느 수준인지 판단하기 어렵다
- `na` 이 능력이 필요한 업무를 맡아보지 않아 판단하기 어렵다

**보완 행동:** 가상 결과물의 사실·수치·출처를 각각 한 곳씩 확인하고 수정 여부를 표시하세요.

**완료 확인:** 확인 근거와 최종 사용 판단을 남김

## P11 · 수정 후 재시험 경험

**질문:** 수정한 요청문이나 처리 방법을 같은 사례와 새로운 사례에 다시 적용하고 결과를 기록한 경험이 있나요?

**확인 의도:** 같은 예시에서만 좋아진 결과와 새 사례에서도 유지되는 방법을 구분해본 경험을 봅니다.

**판단할 항목:**

- 수정 전후를 같은 사례로 비교
- 처음 보는 새 사례에도 적용
- 시험 결과를 기록

**응답 선택지:**

- `consistent` 같은 사례와 새 사례 모두로 재시험하고 결과를 기록해 보았다
- `supported` 재실행은 해봤지만 같은 사례만 확인했거나 기록을 남기지 않았다
- `notyet` 수정 후 다시 시험하거나 결과를 기록한 적은 없다
- `unknown` 관련 경험이 있었는지 명확히 기억나지 않는다
- `na` 이 활동을 수행할 업무 기회가 없었다

**보완 행동:** 수정한 요청문을 기존 사례와 새 사례 각 한 건에 적용하고 결과를 비교하세요.

**완료 확인:** 두 종류 사례의 결과와 실패 사례를 함께 기록함

## P12 · 독립적인 검증 판단

**질문:** AI의 자체 검토가 “문제없음”이라고 합니다. 적절한 확인 방법은 무엇인가요?

**확인 의도:** 같은 AI의 반복 확인을 별도의 검증으로 오인하는지 확인합니다.

**판단할 항목:**

- AI가 스스로 문제없다고 답한 상황

**응답 선택지:**

- `incorrect` 같은 AI가 두 번 확인했으므로 검증 완료로 표시함
- `correct` 사람이 원문·검산·별도 시험으로 확인하고 한계를 기록함
- `unknown` 판단하기 어려움

**보완 행동:** AI의 자체 점검과 사람이 수행한 원문 대조·검산을 나누어 기록하세요.

**완료 확인:** 사람이 직접 확인한 근거를 제시함

## P13 · 동료의 재현 가능성

**질문:** 검증한 AI 활용 방법을 동료가 따라 할 수 있도록 자료·절차·확인 방법을 설명할 수 있나요?

**확인 의도:** 설명을 잘하는지보다 다른 사람이 같은 절차로 실행할 수 있도록 안내할 수 있는지 봅니다.

**판단할 항목:**

- 사용 자료
- 실행 순서
- 결과 확인 방법

**응답 선택지:**

- `consistent` 동료가 따라 할 수 있도록 자료·절차·확인 방법을 설명할 수 있다
- `supported` 활용 방법은 설명할 수 있지만 재현용 자료나 확인 방법은 보완이 필요하다
- `notyet` 내가 쓰는 방법을 동료가 따라 하도록 설명하기 어렵다
- `unknown` 현재 어느 수준인지 판단하기 어렵다
- `na` 이 능력이 필요한 업무를 맡아보지 않아 판단하기 어렵다
