# 관리자 전용 진단 분리

2026-10-19 사용자 결정: 공개 예비 자가진단은 독립적인 서비스이며 전문가 본 진단의 전 단계·신청 경로가 아님. 공개 화면의 전문가 진단 링크·체험·배정·검토·확정·개정 버튼과 JavaScript import/명령 처리기를 제거함.

`index.html`은 비활성 안내만 제공. 클라이언트 화면 숨김·역할 선택으로 관리자 인증을 대신하지 않음. 현재 실제 진단 데이터·접수·검토·확정 API는 연결되지 않음.

향후 실제 관리자 전용 기능 활성화 조건: 기존 운영 권한과 일치하는 인증된 관리자 principal을 서버에서 확인한 뒤에만 진단 생성·열람·검토·확정·개정을 수행. 브라우저가 보내는 role/id를 신뢰하지 않음. 관리자 세션 미인증·일반 회원·다른 기관 계정·미배정 전문가 역할은 허용하지 않음. 기존 홈페이지·학습·지원 CMS의 계정·역할·테이블·정책를 변경하지 않고 별도 검토 후 연결.

공개 응답을 관리자에게 자동 전달하지 않음. 문항·결과는 공개 콘텐츠, 실제 응답·검토 기록은 비공개 업무 데이터로 구분. 현재 도메인 테스트는 서버 인증·접근통제를 입증하는 테스트가 아님.
