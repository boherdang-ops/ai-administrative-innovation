# 진단 사이트 CMS

주소: `https://boherdang-ops.github.io/ai-administrative-innovation/diagnosis/admin/`

기존 Supabase Auth 계정과 `cms_admins` 명단을 사용한다. 신규 계정 생성·관리자 추가·기존 인증 설정 변경은 하지 않는다. 로그인 세션은 이 탭의 sessionStorage에만 보관하며 비밀번호는 보관하지 않는다.

## 운영 순서

1. 기존 관리자 계정으로 로그인한다.
2. 왼쪽 관리 항목에서 내용을 수정한다.
3. 미리보기에서 개인/기관 진단과 결과 화면을 확인한다. 미리보기 응답은 서버에 저장되지 않는다.
4. ‘초안 저장’을 누른다. 저장할 때마다 변경 이력이 자동 생성된다.
5. ‘공개 게시’를 누르면 게시된 콘텐츠가 공개 사이트에 반영된다. 공개 페이지를 새로고침하여 확인한다.

다른 창의 변경과 충돌하면 저장/게시를 중단한다. 편집 내용은 백업 다운로드로 보관한 뒤 ‘최신 초안 불러오기’를 사용한다. 변경 이력은 최근 100건을 화면에 표시하고, 전체 이력은 데이터베이스에 유지한다. 이력 복원과 JSON 백업 불러오기는 편집 중인 초안으로만 불러오며 자동 게시하지 않는다.

## 관리 범위

- 사이트명, 영문 표기, 검색 설명, 로고 URL/업로드, 상단 메뉴 이름·주소·표시 여부, 푸터
- 첫 화면 제목과 소개/카드/이용 안내, 시작 화면/버튼/결과/인쇄 안내 등 공통 문구 405개
- 개인 15문항, 기관 12문항, 5개 과정별 4문항: 질문, 의도, 판단 기준, 답변·설명, 주제, 행동, 완료 기준, 담당, 근거
- 11개 영역의 의미, 문항별 위험과 다음 행동, 개선 확인 기준
- 권장 행동의 이유, 실무자의 확인 요청, 담당자
- 과정명·주소·대안 안내, 관련 서비스 연결

문항 ID·개수·응답 코드의 의미·필수 및 기초 요건 등 판정 구조는 결과 호환성을 위해 보호한다. 판정 알고리즘 변경과 전문가 본 진단의 기록 관리는 콘텐츠 CMS의 범위가 아니다. 기존 법인/교육/학습/실무지원 CMS를 덮어쓰지 않는다.

## 저장·권한·호환성

신규 `diagnosis_cms_drafts`, `diagnosis_cms_published`, `diagnosis_cms_revisions`만 사용한다. 신규 RPC는 SECURITY INVOKER이며 기존 관리자 확인 함수와 RLS를 모두 적용한다. 익명 사용자는 게시 콘텐츠만 조회할 수 있다. 초안·이력 조회와 변경은 관리자만 가능하다. 버전 비교와 행 잠금으로 동시 변경을 감지한다. 직접 API 수정에도 트리거가 구조 검증·이력 기록을 수행한다.

로고는 기존 공개 `site-assets` 버킷의 `diagnosis/` 경로에만 추가한다. 기존 파일·버킷·정책은 수정하지 않는다. PNG/JPG/WebP 최대 3MB로 제한한다. 공개 콘텐츠의 URL은 https만 허용하고, 편집 문구는 HTML로 실행하지 않는다.

공개 화면은 GET으로 게시 콘텐츠만 조회하며 응답·결과·연락처를 전송하지 않는다. 콘텐츠 API 장애 시 기본 콘텐츠로 진단을 계속할 수 있다. 새 진단에 시작 시점의 문항·해석·권장 행동·공통 문구를 함께 복사하므로 이후 게시가 진행 중인 응답·결과에 소급되지 않는다.

SQL 설치 기록: `../integration/diagnosis-cms.sql`. 원격 적용 migration: `diagnosis_content_cms`, `diagnosis_cms_explicit_grants`. 초기 콘텐츠는 현재 `DEFAULT_CONTENT`를 검증해 초안/공개 v1로 생성했다.

## 검증

`node --test diagnosis/tests/*.test.mjs`: 47개 통과. CMS의 10개 편집 영역과 편집→저장→게시→로그아웃 흐름은 mock API로도 시험했다 (`node --experimental-vm-modules diagnosis/tools/check-cms-editor.mjs`). 실제 DB에서 관리자 저장·게시·이력·충돌·구조 보호를 트랜잭션 내 시험 후 rollback했다. 익명/일반 계정의 초안·이력 조회 및 변경 차단과 공개 조회를 확인했다. 신규 CMS 테이블/함수에 보안 advisor 지적 없음. 기존 서비스의 advisor 항목은 변경하지 않았다.

공개 배포 후 개인 15문항 완료·상세 해석·시각화·인쇄 미리보기와 기관/과정 선택을 브라우저에서 확인했다.

기존 브라우저의 자동완성 계정으로 실제 관리자 로그인, 제목 변경 미리보기, 원문 복원, 초안 저장(v2), 공개 게시(v2), 변경 이력 생성을 확인했다. 브라우저 기본 확인 창 대신 CMS 내부의 접근 가능한 확인 창을 사용한다. 계정·비밀번호·관리자 명단은 변경하지 않았다.
